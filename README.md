# 🌊 FloodGuard AI – AI-Powered Flood Monitoring and Disaster Management System

**FloodGuard AI** is an intelligent flood monitoring and disaster management dashboard designed to support emergency response and decision-making during flood situations. It provides real-time-style visualization of flood severity, affected areas, road blockages, shelter availability, emergency resources, and critical infrastructure.

The platform aims to help disaster management teams identify high-risk zones, monitor resource availability, prioritize emergency requests, and plan safer evacuation routes using data-driven insights.

### Key Features
- **Flood Severity Monitoring:** Visualizes flood intensity and identifies high-risk zones.
- **Interactive Flood Map:** Displays affected areas, shelters, hospitals, depots, and blocked roads.
- **Emergency Resource Management:** Tracks shelter capacity, inventory levels, and emergency supply requests.
- **Ambulance Route Planning:** Supports route planning while considering road blockages and accessibility.
- **Infrastructure Risk Monitoring:** Highlights potential cascading failures involving roads, power supply, and hospitals.
- **Time-to-Failure Analysis:** Estimates potential infrastructure failure risks to support proactive decisions.
- **Multilingual Support:** Designed with English and Kannada language accessibility.

### Technology Stack
- Python
- Streamlit
- Plotly
- Jupyter Notebook
- IBM LinuxONE Environment

### Objective
To develop a centralized, intelligent dashboard that transforms flood-related data into actionable insights, helping emergency response teams make faster, informed, and more effective disaster management decisions.
